作品名称：秋招拆弹器
灵感来源：秋招过程中，我发现自己会反复把不同JD、简历和面试问题丢给AI，但每次都是一次性对话，过去的经历和面试结果很难沉淀下来。所以我想做一个真正“越用越懂我”的求职工具，把每次投递和面试变成自己的数据资产。
解决方案：我用REDcowork进行Vibe Coding，从0搭建了“弹药库—JD拆弹—投递看板”的MVP。最大的挑战不是把AI接进来，而是让AI不胡编。我设计了事实确认机制，只有用户确认过的经历才能进入AI分析，并通过数据库记录完整的数据链路。
最惊艳的地方：我最满意的是“面试预测命中率”的设计。AI先根据JD和我的真实经历预测面试问题，面试后再记录实际问题，对比预测与现实的差异。它不是简单告诉我“怎么面试”，而是在持续积累“我到底会被问什么”。
下一步计划：目前作品处于MVP阶段，已经完成核心流程和可运行版本，下一步会找5—20位正在秋招的同学真实使用。重点观察他们是否愿意在面试后回来记录真实问题，并据此完善预测命中率、面试复盘和个性化数据分析。
